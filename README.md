# VTracer Local Web App

<img alt="image" src="https://github.com/user-attachments/assets/2df93435-5ff4-45bf-8874-f5773e4f07f5" />


一个基于 VTracer 的本地离线图片转矢量 SVG 工具，采用现代暗色主题 UI 设计。

## 功能特性

- **完全离线运行** — 无需网络连接，所有处理在本地完成
- **多种上传方式** — 支持拖拽上传、点击选择、Ctrl+V 剪贴板粘贴
- **实时自动转换** — 调整参数后自动重新转换，无需手动点击
- **丰富的参数控制** — 色彩模式、曲线模式、角点阈值、噪点过滤、梯度步长、分段长度、拼接阈值、路径精度等
- **智能参数显示** — 根据当前模式自动隐藏无效参数
- **预览自定义** — 可调整背景色和线条颜色，支持预设快捷切换
- **原图对比** — 长按预览区域查看原始图片，松开后恢复矢量结果
- **导出便捷** — 一键复制 SVG 代码或下载 SVG 文件
- **多语言支持** — 支持中文、英语、法语、俄语、阿拉伯语（联合国安理会五大常任理事国官方语言）
- **主题切换** — 暗色/亮色模式一键切换
- **双语状态提示** — 右上角实时显示转换状态

## 依赖环境

| 项目 | 版本要求 | 说明 |
|------|---------|------|
| Python | 3.10+ | 仅使用标准库，无外部依赖 |
| Windows | 10/11 | vtracer.exe 为 Windows 64 位可执行文件 |

### Python 标准库依赖

- `http.server` / `ThreadingHTTPServer` — HTTP 服务
- `urllib.parse` — URL 解析
- `os`, `io`, `re`, `json`, `subprocess`, `struct`, `shutil` — 系统与工具函数

> 本项目不依赖任何第三方 Python 包，也不需要 `cgi` 模块（已在 Python 3.13 中移除），兼容 Python 3.10 ~ 3.13+。

## 项目结构

```
VTracerApp/
├── app.py              # Python HTTP 服务器（仅标准库）
├── start.bat           # Windows 启动脚本
├── vtracer.exe         # VTracer 0.6.4 核心转换引擎（Rust）
├── index.html          # 主页面
├── static/
│   ├── css/
│   │   └── style.css   # 暗色/亮色主题样式
│   └── js/
│       └── app.js      # 前端交互逻辑、多语言系统
```

## 快速开始

1. 确保系统已安装 Python 3.10 或更高版本
2. 进入 `VTracerApp` 目录
3. 双击 `start.bat` 启动服务
4. 浏览器自动打开 `http://127.0.0.1:8765`

> 关闭 CMD 窗口即可停止服务。

## VTracer 参数说明

| 参数 | 范围 | 说明 |
|------|------|------|
| 色彩模式 | bw / color | 黑白线稿或彩色矢量 |
| 曲线模式 | spline / polygon / pixel | 平滑曲线、多边形、像素 |
| 堆叠模式 | stacked / cutout | 彩色模式下图层组合方式 |
| 色彩精度 | 1 ~ 8 | 颜色量化级别，越高颜色越丰富 |
| 角点阈值 | 0° ~ 180° | 小于此角度的拐角会被平滑 |
| 噪点过滤 | 0 ~ 16 px | 过滤小于此尺寸的孤立噪点 |
| 梯度步长 | 0 ~ 50 | 颜色渐变分层步长，0 为自动 |
| 分段长度 | 2 ~ 18 | 贝塞尔曲线最小分段长度 |
| 拼接阈值 | 0° ~ 180° | 允许拼接两段路径的最大角度差 |
| 路径精度 | 0 ~ 20 | SVG 路径数据小数位数精度 |

> 双击滑块可恢复默认值。

## 技术细节

### 后端
- 基于 `ThreadingHTTPServer` 的并发 HTTP 服务
- 自定义 multipart/form-data 解析器（兼容 Python 3.13，无需 `cgi` 模块）
- 调用 `vtracer.exe` CLI 进行图片转换
- 版本号追踪机制，丢弃过期的异步转换结果

### 前端
- 纯原生 JavaScript，无框架依赖
- 基于 CSS 变量的暗色/亮色主题系统
- i18n 多语言字典系统，支持 RTL（阿拉伯语）
- Debounce 防抖（400ms）避免参数调整时频繁请求
- SVG viewBox 自动补全（修复 VTracer 输出缺少 viewBox 的问题）

## 许可证

VTracer 核心引擎遵循其原始开源许可证。本项目的前端代码和 Python 服务部分可自由使用。
